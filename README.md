# Праздничное приключение — `till-veber.github.io/dr/`

Одностраничная мини-игра из четырёх состояний. Сделана на обычных HTML, CSS и JavaScript: React, npm и сборка не требуются. Переходы между загадками происходят внутри одной страницы, URL не меняется.

## Запуск в WebStorm

1. Распакуйте архив проекта в папку `dr` и откройте эту папку в WebStorm.
2. Откройте `index.html` и запустите через встроенный сервер WebStorm (**Open in Browser** / встроенный preview). Для корректной работы ES-модуля и относительных путей используйте локальный HTTP-сервер, а не `file://`.
3. Для проверки можно также открыть терминал в корне проекта и выполнить:

   ```bash
   python -m http.server 5173
   ```

   Затем откройте `http://localhost:5173/`.

## Публикация на GitHub Pages

Адрес `https://till-veber.github.io/dr/` будет работать, если проект лежит в корне репозитория `dr` аккаунта `till-veber`.

1. На GitHub создайте новый репозиторий **`dr`** в аккаунте **`till-veber`**. Если репозиторий уже создан, используйте его. Для GitHub Free выберите видимость **Public**: GitHub Pages доступен на Free для публичных репозиториев, а опубликованный сайт будет доступен в интернете. При создании не добавляйте автоматически README, `.gitignore` или лицензию.
2. В WebStorm откройте терминал в корневой папке проекта (там, где `index.html`) и выполните:

   ```bash
   git init
   git branch -M main
   git add .
   git commit -m "Create birthday quest page"
   git remote add origin https://github.com/till-veber/dr.git
   git push -u origin main
   ```

   Если `origin` уже настроен, пропустите команду `git remote add origin ...`.
3. На GitHub откройте репозиторий **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве ветки укажите **`main`**, папку — **`/(root)`**, затем нажмите **Save**.
6. После публикации GitHub Pages покажет адрес сайта. Он должен быть `https://till-veber.github.io/dr/`. Первичная публикация может занять несколько минут.

При последующих изменениях достаточно выполнить:

```bash
git add .
git commit -m "Update birthday quest"
git push
```

GitHub Pages автоматически обновит сайт после push.

## Пароли и логика

- Первый экран: `87916`.
- Дневной экран: `NOON` (регистр не важен, ввод автоматически переводится в верхний регистр).
- Ночной экран: любое из имён — Крош, Ёжик/Ежик, Карыч, Кар Карыч/Кар-Карыч, Пин, Копатыч, Лосяш, Совунья, Биби, Бараш, Нюша или Панди. Регистр не важен.
- При ошибке поле встряхивается, очищается и блокируется на 5 секунд; контур вокруг поля постепенно стирается.

**Важно:** пароли находятся в клиентском файле `script.js`, поэтому их можно посмотреть через инструменты разработчика браузера. Это игровая последовательность, а не защита конфиденциальной информации.

## Где менять содержимое

- `index.html` — тексты, подписи и структура четырёх экранов.
- `styles.css` — цвета, размеры, расположение, анимации и адаптивность.
- `script.js` — пароли, список допустимых персонажей, таймер блокировки и случайные цветочки.
- `assets/day.webp` и `assets/night.webp` — дневной и ночной фоны. Это оптимизированные WebP-версии изображений из переданного архива.

Все пути к стилям, скриптам и изображениям относительные (`./...`), поэтому проект корректно открывается из подпапки `/dr/` на GitHub Pages.
